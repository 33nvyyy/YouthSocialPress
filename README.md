# The Youth Social Press\n\nA customizable static journal website for GitHub Pages. Edit `index.html` to change headlines, text, colours, and layout.\n\n## Publish on GitHub Pages\n1. Create a public repository on GitHub (for a project site, e.g. `youthsocialpress`).\n2. Upload `index.html` to the repository root.\n3. Open Settings → Pages.\n4. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, and save.\n5. After deployment, open the Pages URL shown in Settings.\n\nThis is a static site; edit the file and commit changes to update it.\n
